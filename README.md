# 🟢 ASCII Matrix & Image Converter

A futuristic, cyberpunk-themed web application built with **HTML5 Canvas**, **CSS3**, and **Vanilla JavaScript**. It features a classic Matrix digital rain animation and a fully-featured **Image-to-ASCII Converter** that transforms any uploaded image into ASCII art in real-time.

---

## ✨ Features

- **Matrix Rain Mode**: Classic glowing neon-green falling ASCII characters with adjustable speed.
- **Image-to-ASCII Mode**: Upload any image (`.png`, `.jpg`, `.jpeg`) to instantly render it into detailed ASCII art.
- **Customizable Character Ramp**: Modify the character set used for rendering (default: ` .:-=+*#%@`).
- **Resolution Control**: Fine-tune the grid density using the resolution slider (20 to 200 columns).
- **Invert Colors**: Toggle to invert brightness mapping for optimal viewing of different images.
- **Download Support**: Export and download your generated ASCII artwork as a `.txt` file.
- **Responsive & Lightweight**: Fully responsive layout optimized for desktop and mobile screens with zero external dependencies.

## 🚀 How to Launch

### Option 1: Live Preview
Open the [Live Preview](https://raw.githack.com/Suffer404/ascii-matrix/main/index.html) in your browser.

### Option 2: Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Suffer404/ascii-matrix.git
   ```
2. Open `index.html` in any modern web browser.

---

## 🕹️ How to Use

1. **Matrix Rain**: Enjoy the ambient background animation upon opening the app.
2. **Image Converter**: 
   - Click the **IMAGE TO ASCII** tab at the top.
   - Click **UPLOAD IMAGE** and select an image file from your device.
   - Adjust the **Resolution** slider or custom **Characters** string to tweak the detail.
   - Click **DOWNLOAD ASCII** to save your creation.
